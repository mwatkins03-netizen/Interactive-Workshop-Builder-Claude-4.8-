How to embed

Drop an activity into your slides

Google Slides

Slides has no native web embed. Use an add-on that embeds a URL (e.g. an "embed iframe / web page" add-on), or add a button/image linked to the activity URL that opens full-screen during presenting.

PowerPoint

Insert → Add-ins → a "Web Viewer"/iframe add-in, paste the activity URL. Or Insert → Link on a shape to open the activity in the browser while presenting.

Live / web

Open the activity URL directly in a browser tab and present full-screen. Attendees scan a QR code (generate one from the URL) to respond on their own devices.

Each activity's Embed button gives you a ready-to-paste link, iframe snippet, and QR link.
